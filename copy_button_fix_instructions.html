🔧 MCP Platform Copy Button Fix

❌ Problem Identified:

The copy button on prombank-mcp.com fails due to:

  • Unicode character issues (¥, ↗, ✅, 🟢)
  • Browser clipboard API restrictions
  • Large content size (>20,000 characters)
  • Secure context requirements (HTTPS)

✅ Solution Implemented:

Enhanced copy functionality with multiple fallbacks and character cleanup.

🚀 How to Fix Copy Button:

Method 1: Browser Extension (Recommended)

Install Tampermonkey browser extension and add our userscript:

  1. Install Tampermonkey browser extension
  2. Click Tampermonkey icon → "Create a new script"
  3. Replace the template with our userscript code
  4. Save and enable the script
  5. Refresh the MCP platform page

Method 2: Browser Console Fix (Quick)

Paste this code into browser developer console (F12):

// Enhanced Copy Fix for MCP Platform async function mcpCopyFix() { const content = document.querySelector('.content, .article-content, main')?.innerText || ''; if (!content) { alert('No content found to copy'); return; } // Clean problematic characters const cleaned = content .replace(/¥/g, 'CNY ') .replace(/↗/g, '(Improving)') .replace(/✅/g, '[PASS]') .replace(/🟢/g, '[GREEN]') .replace(/🔴/g, '[RED]') .replace(/🟡/g, '[YELLOW]') .replace(/∛/g, 'cbrt') .replace(/÷/g, '/') .replace(/×/g, '*'); try { await navigator.clipboard.writeText(cleaned); alert('✅ Content copied successfully!'); } catch (err) { // Fallback method const textarea = document.createElement('textarea'); textarea.value = cleaned; document.body.appendChild(textarea); textarea.select(); document.execCommand('copy'); document.body.removeChild(textarea); alert('✅ Content copied (fallback method)!'); } } // Run the fix mcpCopyFix();

Method 3: Manual Copy (Always Works)

  1. Switch to Markdown view in the MCP platform
  2. Select all text with Ctrl+A (Cmd+A on Mac)
  3. Copy with Ctrl+C (Cmd+C on Mac)
  4. This bypasses the platform's copy button entirely
